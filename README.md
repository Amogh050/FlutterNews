## 📌 About the Project
FlutterNews is a  **Flutter** application that fetches and displays news articles dynamically using an API. It features **category-based filtering**, **location-based news**, and a user-friendly UI. Additionally, it integrates **Gemini AI** to summarize news articles efficiently.

## 🎯 Features
✅ Fetches real-time news from an API 🌎
✅ Supports multiple news categories 🏷️
✅ Location-based news filtering 📍
✅ Gemini AI integration for news summarization 🤖
✅ Interactive and responsive UI 🎨
✅ Dark Mode Support 🌙

## 🔧 Technologies Used
- **Flutter** (Latest)
- **Dart**
- **News API** (or any other API)
- **Gemini AI** (for summarization)
- **Riverpod** (State Management)
